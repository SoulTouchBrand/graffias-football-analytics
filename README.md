# Graffias Football Analytics

Streamlit web paneli: canlı API-Football maçları, Poisson 1-X-2 olasılıkları, oran karşılaştırması ve CSV backtest.

Streamlit Cloud'da bu depoyu seçin, branch main, main file app.py. Advanced settings > Secrets alanına `API_FOOTBALL_KEY = "YOUR_KEY"` ekleyin.

API anahtarını GitHub'a koymayın. Gol tabanlı tahmin gerçek xG değildir; kazanç garantisi yoktur.
